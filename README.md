# Heap Visualizer

A tiny educational binary min-heap visualizer that prints the heap array after each insertion.

## Features
- Builds a min-heap from a list of integers.
- Shows the internal array after each insertion.
- Prints a simple tree-like view for small heaps.
- Uses Python's standard library.

## Usage
```bash
python heap_visualizer.py 8 3 10 1 6 14
```
